# Teclado Igor

## Opção A — GitHub Actions (sem instalar nada)
1. Crie um repositório no GitHub e envie esta pasta.
2. Aba Actions > "Build APK" > aguarde.
3. Baixe o artefato `teclado-apk` (app-debug.apk) e instale no celular.

## Opção B — Android Studio
Abra a pasta, aguarde o sync e rode Build > Build APK(s).

## Ativando
Abra o app > "Ativar teclado" > ligue "Teclado Igor" > "Escolher teclado".

Dica: toque duas vezes no shift para Caps Lock; segure uma tecla para digitar o símbolo do canto.
